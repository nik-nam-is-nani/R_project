🚀 What Can This System Do? (Capabilities & Features)
⚡
Bulk-First Asynchronous Processing
Submit thousands of recipients in a single request (JSON or CSV file). Processing runs in the background without blocking HTTP requests.
🛡️
Row-Level Fault Isolation
A failed row or rendering error on recipient #450 never stops remaining certificates. Each certificate is rendered and committed independently.
🔍
Validation & Audit Error Storage
Invalid inputs (malformed email, missing name, control chars) are recorded as FAILED records with exact validation reason text rather than dropping data silently.
🎨
ReportLab PDF Engine & Fonts
Generates A4 Landscape vector PDF certificates with bundled Unicode TTF fonts (DejaVuSans) and dynamic font auto-scaling for long names.
📦
Deduplicated ZIP Archive Stream
Package all ready PDF certificates into an in-memory ZIP archive with sanitized, deduplicated filenames (e.g. 001_John_Doe.pdf).
🔒
Public Authenticity Verification
Unique printed verification codes (e.g. CERT-8F3A19B2) allow third parties to verify certificate authenticity instantly at /api/verify/{code}.
